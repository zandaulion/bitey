# Bitey 1.0.15 (`versionCode` 16) — Play release notes

Play Console takes all languages in one box, each wrapped in its locale tag;
`release-notes-1.0.15.xml` beside this file is that paste-ready form, and
this copy is generated from it. Play allows 500 characters per locale; the
longest here, German, is 300.

1.0.15 gives Estimate meal the same wait as a photo (progress bar, a new
playful line every two seconds) and replaces the blanket "check your
connection" with the real reason: only an unreachable server is a connection
problem; other refusals are named, or shown with the server's reason, code
and status. Found on 11 October, when every text estimate failed with
"check your connection" because the deployed function predated text
estimates (fixed by deploying it that day).
