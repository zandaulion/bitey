# Bitey 1.0.13 (`versionCode` 14) — Play release notes

Play Console takes all languages in one box, each wrapped in its locale tag;
`release-notes-1.0.13.xml` beside this file is that paste-ready form, and
this copy is generated from it. All twelve locales are within the 500-character
limit.

1.0.13 adds a focused text entry screen: describe a meal, estimate its calories
and macros with Bitey AI, then review and adjust the result before saving.
Food search and entering nutrition numbers remain free. Text estimates require
the same verified Play subscription as photo estimates and share their daily
allowance. Sending a description has its own consent prompt, and saved text
estimates remain labelled as estimates when reused from recent foods.

Before rollout, deploy the updated `analyse` function to support text requests
and publish the updated privacy page dated 10 October 2026. The signed bundle
does not deploy either change.
