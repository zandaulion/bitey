# Bitey 1.1.9 (`versionCode` 26) — Play release notes

Play Console takes all languages in one box, each wrapped in its locale tag;
`release-notes-1.1.9.xml` beside this file is that paste-ready form, and
this copy is generated from it. Play allows 500 characters per locale; the
longest here, French, is 348.

1.1.9 adds Bitey's first Wear OS companion (its own bundle in the same
listing, versionCode 1000001, version 1.0.0, on Play's Wear OS track). The
phone app gains WatchSync and WatchRequestService: the page sends today and
every quick bite and repeat meal as a ready entry (entryTemplate), the watch
gets names and calories only over the Data Layer, and a tap there is stamped
and written to Room by the phone, with request ids so a lost reply never logs
twice. The home-screen widget follows meals logged on the watch. Watch: app
with a macro-split ring, Undo and back navigation; three tiles (Today, Quick
bites, both); Calories and Macros complications. Tested on paired emulators
and a Galaxy Watch6.
