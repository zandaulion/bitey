# Bitey 1.1.7 (`versionCode` 24) — Play release notes

Play Console takes all languages in one box, each wrapped in its locale tag;
`release-notes-1.1.7.xml` beside this file is that paste-ready form, and
this copy is generated from it. Play allows 500 characters per locale; the
longest here, Spanish, is 214.

1.1.7 raises light-theme contrast to WCAG AA. The page's secondary text
(--ink-3) moves from #758577 to #5D6D60 (3.90:1 to 5.49:1 on white, 3.32:1 to
4.67:1 on the sunken cards) and the accent from #2E8B57 to #287A4D (white text
on it 4.25:1 to 5.27:1). The native parts the CSS does not reach follow: the
action bar's Photo button, the padlock badge, the widget's Photo button and
the long-press shortcut icons. Dark mode is unchanged. It also carries Gradle
9.8.2, Room 2.8.5 and KSP 2.3.12 (with the build's deprecated delegate and
srcDir calls replaced), checked by a release build, a Room upgrade over an
existing database, food search and logging, the widget and the barcode scanner
on a Motorola. Server-side changes in the same period (Express 5, dotenv 18,
the sign-in group semantics, and the Firebase libraries already deployed to
the analyse function) do not ship in the app.
