# Bitey 1.0.6 (`versionCode` 7) — Play release notes

Play Console takes all languages in one box, each wrapped in its locale tag;
`release-notes-1.0.6.xml` beside this file is that paste-ready form, and this
copy is generated from it. Play allows 500 characters per locale; the longest
here, French, is 338.

1.0.6 carries Firebase App Check: each Bitey AI request now brings a Play
Integrity attestation that it comes from this app, installed from Play, on a
genuine device. The server records the result but does not yet refuse
anything; enforcement is switched on only once readings from this build
arrive as valid, so 1.0.5 testers are never locked out. It also adds the
privacy policy link in Settings and says where Bitey's server is on the
consent card.
