# Bitey 1.0.14 (`versionCode` 15) — Play release notes

Play Console takes all languages in one box, each wrapped in its locale tag;
`release-notes-1.0.14.xml` beside this file is that paste-ready form, and
this copy is generated from it. Play allows 500 characters per locale; the
longest here, French, is 158.

1.0.14 lets the profile card on the day view be closed. On a new install it
stayed until weight, height, birth year and activity were all filled in; now
it has a close button, and closing it is remembered. The privacy notice was
also reworded (meal descriptions in their own paragraph), with no change to
what is sent.
